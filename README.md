## What Is This?

AI Success Patterns is an open library of reusable, field-tested approaches to working with AI. Think of it as the "Gang of Four" for AI — not in complexity, but in intent: capture what works, name it, so we can all stop reinventing it.

Patterns are organized into three categories:

| Category | Focus |
|---|---|
| **Conversational** | How to interact with AI models to get better results |
| **Agentic** | How to design AI-assisted workflows and automation |
| **Accuracy** | How to verify, validate, and trust AI output |

## Pattern Format

Each pattern follows a five-element structure:

```
Name        — A memorable, action-oriented label
Context     — The situation where this pattern applies
Problem     — The specific failure mode or friction it addresses
Solution    — The practice, framing, or structural approach
Value       — The measurable or observable consequence of applying it
```
