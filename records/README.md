# Pattern Records

One record per pattern - Pattern 12, Ghost in the Workflow, applied to the library itself. A record is the list Greg would hand to someone if he left the project.

**Each record covers:** purpose; idea providers (with credit and permission status); feedback providers; sources (verified or not); red-team reviews (applied and rejected, with reasons); decisions and rejected framings; status and open questions; connections (related patterns, backlog items, companion skills); history.

**Internal only** - not linked from the site.

**Rule:** Update a pattern's record whenever the pattern changes, is red-teamed, or changes status. New patterns get a record when they are first drafted.

See also `source-verification.md` for the site-wide source check.
