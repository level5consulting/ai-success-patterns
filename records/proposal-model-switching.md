# Proposed addition - switching models (Patterns 25 and 12) - October 29, 2026

**Greg's insight (October 29, 2026, in chat):** using Ghost in the Workflow and The Chat Is Not Your Memory together makes it easy to switch LLMs. Greg pointed ChatGPT at the GitHub repo, and it could take over everything we're doing.

## Pattern 25 - new Value bullet (after "Anyone can pick it up")
- **Switch models without starting over** - the record isn't tied to one AI. Point a different model at it and it picks up the work, so changing tools is a decision, not a restart.

## Pattern 25 - Notes line
- **Greg's test (October 29, 2026):** after weeks of building this library with one AI, Greg pointed ChatGPT at the project's GitHub repository. It could read the records, decisions and drafts and take over the work - because none of it lived only in a chat.

## Pattern 12 - new Value bullet (last)
- **Stay free to change models.** When an AI workflow documents its purpose, inputs, prompts and owner outside any one tool, you can move it to a different model without rebuilding it from memory.
