## Get the skills

Every pattern with a "Use this pattern" prompt is also a ready-made skill. Install the pack once, and your AI runs the patterns when they fit - or when you ask for one by name.

**Eleven skills:** Begin with the End in Mind, Onboard Don't Program, Test Adversarially, Avoid AI Slop with an LLM Interview, Assemble the Team, Ghost in the Workflow, Automate the Invisible, Embed the Expert, The Night Shift, The Staged Journey, Right Tool Right Job.

### Claude Code
In Claude Code, run:

    /plugin marketplace add level5consulting/ai-success-patterns
    /plugin install ai-success-patterns --marketplace level5consulting/ai-success-patterns

Then ask for a pattern by name ("run assemble the team on this draft"), or just work - each skill describes when it applies.

### Claude (claude.ai)
Download a skill's folder from GitHub (skills-pack/skills/<name>), zip it, and upload it under Settings > Capabilities > Skills. [Greg: confirm the menu path when you test - Claude's settings move.]

### Microsoft 365 Copilot (Cowork)
1. Download [ai-success-patterns-copilot.zip](downloads/ai-success-patterns-copilot.zip).
2. In Copilot, open the Cowork tab > Customize > Plugins > Add plugin, and choose the zip.
3. Share it with "Only you" to test, then turn it on.
An admin can also deploy it to everyone from the Microsoft 365 admin center (Agents > All agents > Upload agent).

The skills are the same prompts that are on each pattern page - free to use.
