# Record: Pattern 01 - Begin with the End in Mind

**Category:** Conversational

## Purpose
Names the failure of starting an AI session with no definition of done: output that feels useful but can't be measured, and wasted iterations. Value: every AI interaction is measured against a one-sentence value statement written before the first prompt.
