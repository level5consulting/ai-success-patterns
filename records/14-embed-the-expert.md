# Record: Pattern 14 - Embed the Expert

**Category:** Agentic (Coming Soon card; confirm)
**Maturity level:** Practice (proposed)
**Status:** First draft (`patterns/14-embed-the-expert.md`) - overnight October 16-17, 2026; awaiting live red team

## Purpose
Names the failure of leaving expert judgment personal - shared informally, inconsistently, and lost when the expert leaves. Value: package one expert judgment as a reusable skill so every project gets the expert's first pass.
