# The AI Operations Manager

**Category:** Agentic  
**Status:** Published

---

## Name
The AI Operations Manager

## Context
Multi-step workflows, project coordination, or any recurring process that involves organizing information, tracking status, routing tasks, or synthesizing inputs from multiple sources. Applies when the work is structured but time-consuming — the kind of coordination work that rarely requires judgment but always requires attention.

## Problem
Professionals spend enormous time on coordination work: status updates, meeting prep, follow-up summaries, task routing, and information synthesis. This work is necessary, predictable, and low-judgment — exactly the profile where humans are least valuable and most drained. Delegating it to AI as a one-off task captures some value. Delegating it as a structured, repeatable workflow captures far more.

## Solution
Define a recurring coordination role and assign it to AI as a persistent function, not a one-time task. The "AI Operations Manager" holds the process:
- **Weekly**: Synthesize project status from notes, emails, or tool exports; produce a briefing
- **Meeting prep**: Pull context from prior sessions; draft agenda and talking points
- **Post-meeting**: Capture decisions and action items in a structured format
- **Async updates**: Route information to the right summary document or channel

Structure the AI's role with a standing context document (see *Onboard, Don't Program*) that describes the project, stakeholders, decision history, and current state. Treat each session as a handoff, not a cold start.

## Value Consequence
Coordination overhead — the invisible tax on every knowledge worker's week — drops substantially. The human's attention shifts from managing information to using it. Projects move faster not because the work is different, but because the friction between work and awareness is removed.

---

## Notes
This pattern is the entry point for most agentic AI deployments in professional services. Organizations that implement it at the team level — shared context, shared process, consistent outputs — report the highest satisfaction with AI ROI.

The pattern extends naturally into tool-connected agents (calendar, email, project management) when those integrations are available.
