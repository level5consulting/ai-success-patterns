# Sources

This folder preserves the original posts, articles, and source material that patterns are built from. It exists because context compression in long AI sessions loses pasted text - the pattern pages survive, but the raw sources don't.

**Rule:** Any time a post, article, or external text is pasted into a session as pattern source material, save it here immediately before anything else.
