# PMO / EPMO Lead Starter Pack - ChatGPT version (v0.1)

The same five Start-here patterns plus the pmo-start-here guide, as ChatGPT skills. Skills use the open Agent Skills format: a folder with a SKILL.md file.

## If your ChatGPT workspace has skills
1. Download `pmo-chatgpt-skills.zip` and unzip it. Inside are six small zips, one per skill. Don't unzip those.
2. In ChatGPT, go to Skills > Create > Upload from your computer, and upload one zip. Repeat for all six. (In some accounts Skills sits under Plugins in the sidebar.)
3. Open a new chat and say: "Start here - I'm a PMO lead." ChatGPT can pick a skill on its own, or you can @-mention one.

In Business and Enterprise workspaces, skills may be off until the workspace owner turns them on and lets you create or install them. If you don't see Skills, ask your owner.

## If your plan doesn't have skill upload
Each skill still works as a prompt. Open `skills/<name>/SKILL.md`, copy everything below the top block, and paste it at the start of a chat. Or add the files to a ChatGPT project so each chat in that project can read them.

## Set up your workspace
- **One ChatGPT project per project you manage** (or per program, if your projects are small), with many short chats inside it - The Chat Is Not Your Memory.
- In the project: a **project record**, **reference files** (charter, RAID log, last steering deck, templates) and **standing instructions** (report format, tone, RAG thresholds).
- **One short chat per task.** Each chat reads the record, does the job, and updates the record.
- **One separate portfolio project** for health checks, cross-project prioritization and documenting your AI assets.
- First move: run The Chat Is Not Your Memory on one project to create the record.
