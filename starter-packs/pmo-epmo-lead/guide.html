AI SUCCESS PATTERNS - PMO / EPMO LEAD STARTER PACK

Give your team a common language for AI.

Five named patterns your whole PMO can use in a sentence. When someone hands in AI slop, the question is ten seconds long: Did you run Avoid AI Slop?

Get started in 15 minutes

  1. Unzip the pack. Inside is one small zip per skill.
  2. In Claude: Customize > Skills - upload the six skill zips; you can select all six in one step. (ChatGPT: download the ChatGPT version, with setup steps in its README.)
  3. Open a new chat and say: "Start here - I'm a PMO lead."
  4. Set up one Claude project per project you manage (one more for portfolio work), with a project record from The Chat Is Not Your Memory and one short chat per task, each ending the same way: ask for the agenda, update the record with it. No projects on your plan? Attach the record file to each chat.
  5. Run one skill on real work this week - your next status report is a good first job.

The five skills - the Start-here path

PatternUse it when
1Avoid AI Slop
with an LLM Interview		Writing a status report, business case or steering committee update. The AI interviews you first, so the draft carries what only you know.
2The Chat Is Not Your MemoryAny work that runs past one session. Decisions, sources and the RAID log live in a project record the AI reads first.
3The Night ShiftPortfolio health checks, report drafts and RAID reviews that can run while you're in meetings. Findings only - nothing changes in your PPM tool.
4Assemble the TeamBefore a business case or prioritization decision goes out. Hear the CFO, the skeptical sponsor and the delivery lead first.
5Ghost in the WorkflowFor every AI prompt, agent or automation your PMO depends on - so it outlasts the person who built it.

  • Is that in the project record, or just the chat?
  • Put it on the night shift.

  • Who owns that agent - is there a record?
