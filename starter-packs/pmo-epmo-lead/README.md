# PMO / EPMO Lead Starter Pack (v0.1 - Claude, ChatGPT and Gemini)

**Give your team a common language for AI.** When everyone knows what "Avoid AI Slop" or "The Night Shift" means, a ten-minute explanation becomes a ten-second question.

The five Start-here AI Success Patterns as skills, each with a "For PMO and EPMO leads" section, plus a **pmo-start-here** guide.

| Skill | Use it for |
|---|---|
| pmo-start-here | Where to begin; picks a skill for this week's work; what to read next |
| avoid-ai-slop-with-an-llm-interview | Status reports, business cases, steering committee updates |
| the-chat-is-not-your-memory | A project record the AI reads every session |
| the-night-shift | Portfolio health checks and report drafts while you're in meetings |
| assemble-the-team | Red-teaming a business case or prioritization decision |
| ghost-in-the-workflow | Documenting the AI tools your PMO depends on |

## Install
- **Claude (web, desktop):** download `pmo-claude-skills.zip`, unzip it, and go to Customize > Skills and upload the six skill zips from `claude/zips/` - you can select all six in one step.
- **Claude Code:** `/plugin marketplace add level5consulting/ai-success-patterns`, then `/plugin install ai-success-patterns-pmo@ai-success-patterns`.
- **ChatGPT:** download `chatgpt/pmo-chatgpt-skills.zip`; setup steps are in `chatgpt/README.md`.
- **Gemini (personal Google accounts for now):** download `gemini/pmo-gemini-skills.zip`; setup steps are in `gemini/README.md`.
- Then say: "Start here - I'm a PMO lead."

## Set up your workspace
- **One Claude project per project you manage** (or per program, if your projects are small), with many short chats inside it - The Chat Is Not Your Memory.
- In the project: a **project record** (decisions, sources, open items, stakeholders, status - The Chat Is Not Your Memory builds it), **reference files** (charter, RAID log, last steering deck, templates) and **standing instructions** (report format, tone, RAG thresholds).
- **One short chat per task** - this month's status report, a business case red-team, a RAID review. Each chat reads the record, does the job, asks for the agenda, and updates the record with it. The agenda opens the next chat.
- **One separate portfolio project** for health checks, cross-project prioritization and documenting your AI assets.
- No projects on your plan? Keep the project record as a file and paste or attach it at the start of each chat.
- First move: run The Chat Is Not Your Memory on one project to create the record.
