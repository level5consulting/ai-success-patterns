# PMO / EPMO Lead Starter Pack (v0.1 - Claude version)

The five Start-here AI Success Patterns as skills, each with a "For PMO and EPMO leads" section, plus a **pmo-start-here** guide.

| Skill | Pattern | Use it for |
|---|---|---|
| pmo-start-here | - | Where to begin; picks a skill for this week's work; what to read next |
| avoid-ai-slop-with-an-llm-interview | 05 | Status reports, business cases, steering committee updates |
| the-chat-is-not-your-memory | 25 | A project record the AI reads every session |
| the-night-shift | 15 | Portfolio health checks and report drafts while you're in meetings |
| assemble-the-team | 08 | Red-teaming a business case or prioritization decision |
| ghost-in-the-workflow | 12 | Documenting the AI tools your PMO depends on |

## Install
- **Claude (web, desktop):** download `pmo-claude-skills.zip`, unzip it, and upload each skill folder's zip in Settings > Capabilities > Skills (one zip per skill: `claude/zips/`).
- **Claude Code:** `/plugin marketplace add level5consulting/ai-success-patterns`, then `/plugin install ai-success-patterns-pmo@ai-success-patterns`.
- Then say: "Start here - I'm a PMO lead."
