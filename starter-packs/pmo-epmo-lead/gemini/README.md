# PMO / EPMO Lead Starter Pack - Gemini version (v0.1, being tested)

The same five Start-here patterns plus the pmo-start-here guide, as Gemini skills. Skills use the open Agent Skills format: a folder with a SKILL.md file.

## Add the skills
Use Gemini on the web (gemini.google.com) or the Gemini Mac app - uploading doesn't work on phones yet.
1. Download `pmo-gemini-skills.zip` and unzip it. Inside are six folders, one per skill. Keep the folder names as they are.
2. In Gemini, go to **Customize > Skills** and upload one folder. Repeat for all six.
3. Open a new chat and say: "Start here - I'm a PMO lead." Gemini can pick a skill on its own, or type / and the skill's name.

Skills are on personal Google accounts now. Google says work and school accounts are coming soon. If you don't see Skills, that's probably why.

## If you can't add skills
Each skill still works as a prompt. Open `skills/<name>/SKILL.md`, copy everything below the top block, and paste it at the start of a chat.

## Set up your workspace
- **One Google Drive folder per project you manage** (or per program, if your projects are small), with many short chats that read from it - The Chat Is Not Your Memory.
- In that folder: a **project record**, **reference files** (charter, RAID log, last steering deck, templates) and **standing instructions** (report format, tone, RAG thresholds).
- **One short chat per task.** Attach the record, do the job, ask for the agenda, and update the record with it. The agenda opens the next chat.
- **One separate portfolio folder** for health checks, cross-project prioritization and documenting your AI assets.
- First move: run The Chat Is Not Your Memory on one project to create the record.
